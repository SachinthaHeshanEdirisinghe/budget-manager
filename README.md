# Personal Budget & Expense Manager

A React Native (Expo) mobile app to track income, expenses and monthly budget.

## Features
- Dashboard with balance, income and expenses
- Add income and expense transactions with categories
- Filter and delete transactions
- Monthly budget with progress bar and warnings
- Statistics: income vs expenses and spending by category
- Data saved on the device with AsyncStorage

## Tech stack
React Native, Expo, React Navigation, AsyncStorage, expo-linear-gradient, Ionicons

## Run the project
npm install
npm start
Scan the QR code with the Expo Go app.
